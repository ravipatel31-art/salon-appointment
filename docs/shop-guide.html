Shop guide for staff & counter — services, online advance rules, booking flow, and the owner admin panel.

What customers see

Customers book from the mobile app: pick a barber → service + wash → date & 15-minute slot → pay 50% advance online (Razorpay) → booking is confirmed. They show up, use the service, and pay the balance at the counter.

Advance rule: fixed services → online advance = 50% of total (rounded up). Hair color → fixed ₹100 online; admin sets the final price at the shop and balance is collected there. Cancel ≥ 2 hours before the slot → automatic refund of the advance; later cancel → advance is forfeited.

Counter flow (staff)

  1. Customer arrives → check My bookings on their phone, or open the Admin panel → Bookings.
  2. Unpaid slots disappear after 12 minutes automatically (hold expiry).
  3. After service: Admin panel → booking → Complete (hair color: enter final ₹ at center). Balance = final − online paid.
  4. No-show → mark No show in the panel.
  5. Refunds (cancel ≥ 2h) are processed from the payment side; status becomes Refunded.

Owner admin panel

Pages (browser):

  • Login — own page (no dashboard until signed in)
  • Dashboard — daily bookings & revenue
  • Barbers — name, photo, bio, weekly hours
  • Services — edit the salon plan (₹ / duration)
  • Bookings — filters, complete / no-show

Local addresses:

  • Panel home: http://localhost:8000/panel
  • Login: http://localhost:8000/panel/login
  • Dashboard: http://localhost:8000/panel/dashboard
  • API health: http://localhost:8000/health

Same admin email/password as the seed in .env.

Running the system (Docker)

The whole stack is Docker Compose: Postgres + API (migrations → seed → server → admin panel static files). Rebuild once after code changes; otherwise a restart is enough: 

# first time / after code changes
docker compose up -d --build

# day-to-day (after machine reboot, etc.)
docker compose restart
# or
docker compose up -d

# status
docker compose ps
curl -f http://localhost:8000/health

Data persists in volume salon_pgdata. Env secrets live in root .env (never commit). For public HTTPS (Razorpay webhooks) use Caddy or a Cloudflare tunnel in front of port 8000 — see deploy/NOTES.md.
